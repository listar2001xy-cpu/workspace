# 架构设计 v0.1

## 分层

```
┌─────────────────────────────────────────┐
│  app/        状态机主循环                │  ← 业务流程，无硬件依赖
├─────────────────────────────────────────┤
│  core/       采样引擎 sampler / autorange│  ← 纯逻辑，可单测
│  transport/  帧编解码 frame / ble 发送   │
├─────────────────────────────────────────┤
│  hal/        i_adc.h 接口 + ads1220 实现 │  ← 硬件相关，唯一碰寄存器的地方
└─────────────────────────────────────────┘
```

**依赖方向**：上层依赖下层，下层绝不依赖上层。`hal` 是唯一知道芯片型号的层。

## 关键抽象：ADC 接口

上层（core/app）只依赖 `IResistanceAdc`，不依赖 `ADS1220`。

```
IResistanceAdc (firmware/src/hal/i_adc.h)
        ▲
        │ 实现
   ┌────┴────┬──────────┬──────────┐
Ads1220Adc  Ads1256Adc  Ad7124Adc   ← 换芯片 = 新增一个文件
```

- 换芯片 / 加 8 通道：只改 `hal/` 下的实现，`core/` 与 `app/` 不动。
- `core/` 里的 `autorange`、`sampler`、`frame` 是纯逻辑，无硬件调用，可在 PC 上跑 Unity 单测。

## 数据流

```
ADS1220 连续转换 → DRDY 中断 → 环形缓冲 → 抽取(÷2/÷4/÷20) → 帧编码 → BLE notify
                                        ↑
                                    自动换挡（改 IDAC+PGA）
```

采样节奏由 ADS1220 硬件时钟决定，ESP32 被动响应，避免 RTOS 调度抖动。
